---
title: Migration Overview
---

This Docusaurus project rebuilds `ballerina.io` from Next.js into a static
Docusaurus site.

The goal is not only to move content. We also need to preserve:

- the existing public URL structure for SEO
- the current staging and production branch flow
- the static-export deployment model
- generated sections such as Ballerina By Example

The next docs capture the working migration plan, URL strategy, and deployment
constraints so implementation can proceed in controlled steps.
