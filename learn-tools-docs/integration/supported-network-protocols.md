Ballerina supports the network integration protocols listed below.


| Protocol | Description                                                                                                                                 | Documentation                                                                                                                                                                                                                                                                                                                                                                                                  |
|-------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [HTTP](https://central.ballerina.io/ballerina/http)                          | HTTP client/server functionalities to produce and consume HTTP APIs                                                                         | <ul> <li> [HTTP client](https://lib.ballerina.io/ballerina/http/latest#Client)<br /> </li> <li> [HTTP listener](https://lib.ballerina.io/ballerina/http/latest#Listener) </li> </ul>                                                                                                                                                              |
| [gRPC](https://central.ballerina.io/ballerina/grpc)                          | gRPC client/server functionalities to produce and consume gRPC APIs                                                                         | <ul> <li> [gRPC client](https://lib.ballerina.io/ballerina/grpc/latest#Client)<br /> </li> <li> [gRPC listener](https://lib.ballerina.io/ballerina/grpc/latest#Listener) </li> </ul>                                                                                                                                                              |
| [WebSocket](https://central.ballerina.io/ballerina/websocket)                    | WebSocket client/server functionalities to produce and consume WebSocket APIs                                                             | <ul> <li> [WebSocket client](https://lib.ballerina.io/ballerina/websocket/latest#Client)<br /> </li> <li> [WebSocket listener](https://lib.ballerina.io/ballerina/websocket/latest#Listener) </li> </ul>                                                                                                                                          |
| [WebSub](https://central.ballerina.io/ballerina/websub)                        | APIs for the functionalities of the WebSub subscriber                                                            | <ul><li> [WebSub listener](https://lib.ballerina.io/ballerina/websub/latest#Listener)</li></ul>                                     |
| [WebSubHub](https://central.ballerina.io/ballerina/websubhub)                        | APIs for the functionalities of the WebSubHub and WebSub publisher                                                             | <ul><li> [WebSubHub listener](https://lib.ballerina.io/ballerina/websubhub/latest#Listener)<br /> </li><li> [WebSubHub publsiher client](https://lib.ballerina.io/ballerina/websubhub/latest#PublisherClient)</li></ul>                                     |
| [GraphQL](https://central.ballerina.io/ballerina/graphql)                       | GraphQL client/server functionalities to produce and consume GraphQL APIs                                                                   | <ul> <li> [GraphQL client](https://lib.ballerina.io/ballerina/graphql/latest#Client)<br /> </li> <li> [GraphQL listener](https://lib.ballerina.io/ballerina/graphql/latest#Listener) </li> </ul>                                                                                                                                                  |
| [TCP](https://central.ballerina.io/ballerina/tcp)                            | Send and receive messages to/from another application process (local or remote) over the connection-oriented TCP protocol | <ul> <li> [TCP client](https://lib.ballerina.io/ballerina/tcp/latest#Client)<br /> </li> <li> [TCP listener](https://lib.ballerina.io/ballerina/tcp/latest#Listener) </li> </ul>                                                                                                                                                                  |
| [FTP/SFTP](https://central.ballerina.io/ballerina/ftp)                      | FTP/SFTP client/server functionalities to facilitate file handling in a remote file system                                               | <ul> <li> [FTP client](https://lib.ballerina.io/ballerina/ftp/latest#Client)<br /> </li> <li> [FTP listener](https://lib.ballerina.io/ballerina/ftp/latest#Listener) </li> </ul>                                                                                                                                                                  |
| [SMTP](https://central.ballerina.io/ballerina/email)                          | Send emails via the SMTP protocol using the SMTP client                                                        | <ul> <li> [SMTP client](https://lib.ballerina.io/ballerina/email/latest#SmtpClient) </li> </ul>                                                                                                                                                                                                                                                                            |
| [POP3](https://central.ballerina.io/ballerina/email)                          | Receive emails via the POP3 protocol using both clients and services                                              | <ul> <li> [POP3 client](https://lib.ballerina.io/ballerina/email/latest#PopClient)<br /> </li> <li> [POP3 listener](https://lib.ballerina.io/ballerina/email/latest#PopListener) </li> </ul>                                                                                                                                                      |
| [IMAP4](https://central.ballerina.io/ballerina/email)                          | Receive emails via the IMAP4 protocol using both clients and services                                             | <ul> <li> [IMAP4 client](https://lib.ballerina.io/ballerina/email/latest#ImapClient)<br /> </li> <li> [IMAP4 listener](https://lib.ballerina.io/ballerina/email/latest#ImapListener) </li> </ul>                                                                                                                                                  |
| [JMS](https://central.ballerina.io/ballerinax/java.jms)                           | Send and receive messages by connecting to a JMS provider                                                        | <ul> <li> [Message producer](https://lib.ballerina.io/ballerinax/java.jms/latest#MessageProducer)<br /> </li> <li> [Message consumer](https://lib.ballerina.io/ballerinax/java.jms/latest#MessageConsumer)<br /> </li> <li> [Message listener](https://lib.ballerina.io/ballerinax/java.jms/latest#Listener) </li> </ul> |
| [AMQP](https://central.ballerina.io/ballerinax/rabbitmq)                          | Send and receive messages by connecting to the RabbitMQ server                                                    | <ul> <li> [RabbitMQ client](https://lib.ballerina.io/ballerinax/rabbitmq/latest#Client)<br /> </li> <li> [RabbitMQ listener](https://lib.ballerina.io/ballerinax/rabbitmq/latest#Listener) </li> </ul>                                                                                                                                            |
| [AWS SQS](https://central.ballerina.io/ballerinax/aws.sqs)                       | Perform operations related to queues and messages by connecting to AWS SQS                                        | <ul> <li> [AWS SQS client]( https://lib.ballerina.io/ballerinax/aws.sqs/latest#Client ) </li> </ul>                                                                                                                                                                                                                                                                           |
| [MQTT](https://central.ballerina.io/ballerina/mqtt)                          | Publish and subscribe messages by connecting to an MQTT server                                                     | <ul> <li> [MQTT client](https://lib.ballerina.io/ballerina/mqtt/latest#Client)<br /> </li> <li> [MQTT listener](https://lib.ballerina.io/ballerina/mqtt/latest#Listener) </li> </ul>                                                                                                                                                              |
| [SOAP](https://central.ballerina.io/ballerina/soap)                          | Send and receive messages by connecting to a SOAP service                                                         | <ul> <li> [SOAP client](https://lib.ballerina.io/ballerina/soap/latest) </li> </ul>                                                                                                                                                                                                                                                                                        |
