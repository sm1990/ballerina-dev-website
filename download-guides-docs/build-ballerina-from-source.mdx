## Overview

<RawHtml html={"<p><a href=\"#building-the-complete-ballerina-distribution\">Building the complete Ballerina distribution</a> provides you access to all the main features of Ballerina such as the runtime, corresponding tools, standard library modules etc.</p>\n<blockquote>\n<p><strong>Info:</strong> However, if you need just a plain Ballerina language build with only the basic language features and the JBallerina Java (Java Introp) API in it, you can <a href=\"#building-only-the-ballerina-runtime-with-the-tools\">build only the Ballerina Runtime with the tools</a></p>\n</blockquote>"} />

## Set up the prerequisites

<RawHtml html={"<p>Follow the steps below to set up the prerequisites.</p>\n<ol>\n<li>\n<p>Download and <a href=\"https://adoptopenjdk.net/installation.html\">set up</a> OpenJDK 21 (<a href=\"https://adoptopenjdk.net/\">Adopt OpenJDK</a> or any other OpenJDK distribution).</p>\n<blockquote>\n<p><strong>Info:</strong> You can also use <a href=\"https://www.oracle.com/java/technologies/javase-downloads.html\">Oracle JDK</a>.</p>\n</blockquote>\n</li>\n<li>\n<p>Set up a <a href=\"https://docs.github.com/en/github/authenticating-to-github/keeping-your-account-and-data-secure/creating-a-personal-access-token\">Personal Access Token</a> for your GitHub account and configure the following environment variables (the access token should have the <code>read</code> package permission).</p>\n<p><strong>For Unix/macOS:</strong></p>\n<pre><code>export packageUser=&quot;&lt;YOUR_GITHUB_USERNAME&gt;&quot;;\nexport packagePAT=&quot;&lt;YOUR_PERSONAL_ACCESS_TOKEN&gt;&quot;;\n</code></pre>\n<p><strong>For Windows:</strong></p>\n<pre><code>set packageUser=&lt;YOUR_GITHUB_USERNAME&gt;\nset packagePAT=&lt;YOUR_PERSONAL_ACCESS_TOKEN&gt;\n</code></pre>\n</li>\n</ol>"} />

## Build the complete Ballerina distribution

<RawHtml html={"<p>Follow the steps below to build the <a href=\"https://github.com/ballerina-platform/ballerina-distribution\"><code>ballerina-distribution</code> repository</a> to get full access to the complete Ballerina distribution.</p>\n<ol>\n<li>\n<p>Fork the <code>ballerina-distribution</code> repository to your GitHub account and execute following command to clone it.</p>\n<pre><code>$ git clone --recursive https://github.com/&lt;GITHUB_USERNAME&gt;/ballerina-distribution.git\n</code></pre>\n</li>\n<li>\n<p>Navigate to the <code>&lt;BALLERINA_DISTRIBUTION_PROJECT&gt;</code> directory, and execute the command below to start the build (here, the tests are excluded to speed up the build).</p>\n<p><strong>For Unix/macOS:</strong></p>\n<pre><code>$ ./gradlew clean build -x test\n</code></pre>\n<p><strong>For Windows:</strong></p>\n<pre><code>$ gradlew clean build -x test\n</code></pre>\n</li>\n<li>\n<p>Extract the built Ballerina Language distribution (i.e., the <code>&lt;BALLERINA_DISTRIBUTION_PROJECT&gt;/ballerina/build/distributions/ballerina-&lt;VERSION&gt;.zip</code> file) to a preferred location.</p>\n</li>\n<li>\n<p>Configure the environment variables below.</p>\n<p><strong>For Unix/macOS:</strong></p>\n<pre><code># Set up the `BALLERINA_HOME` environment variable.\nexport BALLERINA_HOME=&quot;&lt;YOUR_LOCATION&gt;/ballerina-&lt;VERSION&gt;&quot;;\n\n# Include the binaries to the system `PATH`.\nPATH=$BALLERINA_HOME/bin:$PATH;\nexport PATH;\n</code></pre>\n<p><strong>For Windows:</strong></p>\n<pre><code># Set up the `BALLERINA_HOME` environment variable.\nset BALLERINA_HOME=&quot;&lt;YOUR_LOCATION&gt;\\ballerina-&lt;VERSION&gt;&quot;;\n\n# Include the binaries to the system `PATH`.\nset PATH=%PATH%;%BALLERINA_HOME%\\bin;\n</code></pre>\n</li>\n</ol>"} />

### Test the distribution build

<RawHtml html={"<p>Since this is a complete Ballerina distribution build, this will have all the Standard Library module dependencies included in it.</p>\n<p>Therefore, follow the steps below to write a simple program using the Ballerina <a href=\"https://github.com/ballerina-platform/module-ballerina-io/\"><code>io</code> module</a> to test the distribution build.</p>\n<ol>\n<li>\n<p>Create a <code>hello_world_with_io.bal</code> file with the code below.</p>\n<pre><code class=\"language-ballerina\">import ballerina/io;\n\n// ballerina hello world program\npublic function main() {\n      io:println(&quot;Hello, World with IO!&quot;);\n}\n</code></pre>\n</li>\n<li>\n<p>Execute the command below to build and run this program.</p>\n<pre><code>$ bal run hello_world_with_io.bal\n</code></pre>\n<p>If your build is successful, you view the output below.</p>\n<pre><code>Hello, World with IO!\n</code></pre>\n</li>\n</ol>"} />

## Build only the Ballerina runtime with the tools

<RawHtml html={"<p>Follow the steps below to build just the Ballerina runtime with the corresponding tools.</p>\n<ol>\n<li>\n<p>Fork the <a href=\"https://github.com/ballerina-platform/ballerina-lang\"><code>ballerina-lang</code> repository</a> to your GitHub account and execute following command to clone it.</p>\n<pre><code>$ git clone --recursive https://github.com/&lt;GITHUB_USERNAME&gt;/ballerina-lang.git\n</code></pre>\n</li>\n<li>\n<p>Navigate to the <code>&lt;BALLERINA_LANG_PROJECT&gt;</code> directory, and execute the command below to update the Git submodules.</p>\n<pre><code>$ git submodule update --init\n</code></pre>\n</li>\n<li>\n<p>Execute one of the commands below to start the build process.</p>\n<p><strong>For Unix/macOS:</strong></p>\n<pre><code>$ ./gradlew clean build\n</code></pre>\n<p><strong>For Windows:</strong></p>\n<pre><code>$ gradlew clean build\n</code></pre>\n</li>\n<li>\n<p>Extract the built Ballerina Language distribution (i.e., the <code>&lt;BALLERINA_LANG_PROJECT&gt;/distribution/zip/jballerina-tools/build/distributions/jballerina-tools-&lt;VERSION&gt;.zip</code> file) to a preferred location.</p>\n</li>\n<li>\n<p>Configure the environment variables below.</p>\n<p><strong>For Unix/macOS:</strong></p>\n<pre><code># Set up the `BALLERINA_HOME` environment variable.\nexport BALLERINA_HOME=&quot;&lt;YOUR_LOCATION&gt;/jballerina-tools-&lt;VERSION&gt;&quot;;\n\n# Include the binaries to the system `PATH`.\nPATH=$BALLERINA_HOME/bin:$PATH;\nexport PATH;\n</code></pre>\n<p><strong>For Windows:</strong></p>\n<pre><code># Set up the `BALLERINA_HOME` environment variable.\nset BALLERINA_HOME=&quot;&lt;YOUR_LOCATION&gt;\\jballerina-tools-&lt;VERSION&gt;&quot;;\n\n# Include the binaries to the system `PATH`.\nset PATH=%PATH%:%BALLERINA_HOME%\\bin;\n</code></pre>\n</li>\n</ol>"} />

### Test the runtime build

<RawHtml html={"<p>Since this runtime build is just a plain Ballerina language build, you only have the basic language features and JBallerina Java (Java Introp) API in it.</p>\n<p>Therefore, follow the steps below to write a basic Ballerina program using only those functionalities to test the runtime build.</p>\n<ol>\n<li>\n<p>Create a <code>hello_world.bal</code> file with the code below.</p>\n<pre><code class=\"language-ballerina\">import ballerina/jballerina.java;\n\npublic function main(string... args) {\n    var systemOut = out();\n    println(systemOut, java:fromString(&quot;Hello, World!&quot;));\n}\n\n// Retrieves the current System output stream\npublic function out() returns handle = @java:FieldGet {\n    name: &quot;out&quot;,\n    'class: &quot;java.lang.System&quot;\n} external;\n\n// Calls `println` method of the  `PrintStream`\nfunction println(handle receiver, handle message) = @java:Method {\n    paramTypes: [&quot;java.lang.String&quot;],\n    'class: &quot;java.io.PrintStream&quot;\n} external;\n</code></pre>\n</li>\n<li>\n<p>Execute the command below to build and run this program.</p>\n<pre><code>$ bal run hello_world.bal\n</code></pre>\n<p>If your build is successful, you view the output below.</p>\n<pre><code>Hello, World!\n</code></pre>\n</li>\n</ol>"} />
