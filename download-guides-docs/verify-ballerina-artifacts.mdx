## Verify using the Cosign CLI

<RawHtml html={"<p>Below is an example of using the Cosign CLI to verify the release artifacts of the MacOS platform.</p>\n<blockquote>\n<p><strong>Info:</strong> You can select the verification artifacts you want to verify based on your installer from the ones listed in the table above.</p>\n</blockquote>\n<p>Follow the steps below to verify the artifacts using the Cosign CLI.</p>\n<ol>\n<li>\n<p>Download the desired artifact from the table above.</p>\n</li>\n<li>\n<p>Execute the command below to verify the artifacts.</p>\n<pre><code>$ cosign verify-blob ballerina-2201.13.2-swan-lake-macos-x64.pkg --certificate ballerina-2201.13.2-swan-lake-macos-x64.pkg.pem --signature ballerina-2201.13.2-swan-lake-macos-x64.pkg.sig --certificate-identity=https://github.com/ballerina-platform/ballerina-distribution/.github/workflows/publish-release.yml@refs/heads/2201.13.x --certificate-oidc-issuer=https://token.actions.githubusercontent.com\n</code></pre>\n</li>\n</ol>\n<p>If the artifact matches the one signed by Cosign, you will receive the following message.</p>\n<pre><code>Verified OK\n</code></pre>"} />

## Verify using the Rekor API

<RawHtml html={"<p>The signatures applied on the Ballerina release artifacts are recorded in <a href=\"https://github.com/sigstore/rekor\">Rekor</a>, which is a Sigstore Transparency Log. Below is an example of using the Rekor API to verify the release artifacts of the MacOS platform.</p>\n<blockquote>\n<p><strong>Info:</strong> You can select the verification artifacts you want to verify based on your installer from the ones listed in the table above.</p>\n</blockquote>\n<p>Follow the steps below to send an API call to Rekor to retrieve and verify the details of the <code>signature</code> and the <code>certificate chain</code>.</p>\n<ol>\n<li>\n<p>Download the desired artifact from the table above.</p>\n</li>\n<li>\n<p>Generate an SHA256 Hash for the artifact and store it in a variable.</p>\n<pre><code>$ SHASUM=$(shasum -a 256 ballerina-2201.13.2-swan-lake-macos-x64.pkg |awk '{print $1}')\n</code></pre>\n</li>\n<li>\n<p>Invoke the Rekor API to retrieve the entry of the signature and store it as the UUID value.</p>\n<pre><code>$ curl -X POST -H &quot;Content-type: application/json&quot; 'https://rekor.sigstore.dev/api/v1/index/retrieve' --data-raw &quot;{\\&quot;hash\\&quot;:\\&quot;sha256:$SHASUM\\&quot;}&quot;\n</code></pre>\n</li>\n<li>\n<p>Assign the UUID returned by the above API call to a variable  as shown below.</p>\n<blockquote>\n<p><strong>Tip:</strong> Replace the <code>&lt;UUID_VALUE&gt;</code> in the below exmaple with the UUID value you recieved</p>\n</blockquote>\n<pre><code>$ UUID=&lt;UUID_VALUE&gt;\n</code></pre>\n</li>\n<li>\n<p>Retrieve the log entry of the artifact signature by sending an API call to Rekor with the assigned UUID variable.</p>\n<pre><code> $ curl -X GET &quot;https://rekor.sigstore.dev/api/v1/log/entries/${UUID}&quot;\n</code></pre>\n</li>\n<li>\n<p>Retrieve the signature and public certificate, which are required to verify the artifact.</p>\n<ul>\n<li>\n<p><strong>Retrieve the signature:</strong></p>\n<pre><code>$ curl -s -X GET &quot;https://rekor.sigstore.dev/api/v1/log/entries/${UUID}&quot; | jq -r '.[] | .body' | base64 -d |jq -r '.spec .signature .content' | base64 -d &gt; ballerina-2201.13.2-swan-lake-macos-x64.pkg.sig\n</code></pre>\n</li>\n<li>\n<p><strong>Retrieve the certificate:</strong></p>\n<pre><code>$ curl -s -X GET &quot;https://rekor.sigstore.dev/api/v1/log/entries/${UUID}&quot;  | jq -r '.[] | .body' | base64 -d |jq -r '.spec .signature .publicKey .content'  | base64 -d &gt; ballerina-2201.13.2-swan-lake-macos-x64.pkg.crt\n</code></pre>\n</li>\n</ul>\n</li>\n<li>\n<p>Extract the <code>public key</code> from the <code>certificate</code> file using <code>openssl</code>.</p>\n<pre><code>$ openssl x509 -in ballerina-2201.13.2-swan-lake-macos-x64.pkg.crt -noout -pubkey &gt; ballerina-2201.13.2-swan-lake-macos-x64.pkg.pubkey.crt\n</code></pre>\n</li>\n<li>\n<p>Verify the artifact using the public key.</p>\n<pre><code>$ openssl sha256 -verify ballerina-2201.13.2-swan-lake-macos-x64.pkg.pubkey.crt -signature ballerina-2201.13.2-swan-lake-macos-x64.pkg.sig ballerina-2201.13.2-swan-lake-macos-x64.pkg\n</code></pre>\n</li>\n</ol>\n<p>If the artifact matches the one signed by <code>Cosign</code>, you will receive the following message.</p>\n<pre><code>Verified OK\n</code></pre>"} />
