## Overview of Ballerina Swan Lake Update 12 (2201.12.12)

<em>Swan Lake Update 12 (2201.12.12) is the twelfth patch release of Ballerina 2201.12.0 (Swan Lake Update 12) and it includes a new set of bug fixes.</em>

## Update Ballerina

Run the command below to update your current Ballerina installation directly to 2201.12.12 by using the [Ballerina Update Tool](https://ballerina.io/learn/update-tool/).

```
$ bal dist pull 2201.12.12
```

## Install Ballerina

If you have not installed Ballerina, then, download the [installers](/downloads/) to install.
