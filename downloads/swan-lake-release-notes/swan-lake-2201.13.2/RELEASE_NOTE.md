## Overview of Ballerina Swan Lake Update 13 (2201.13.2)

<em>Swan Lake Update 13 (2201.13.2) is the second patch release of Ballerina 2201.13.0 (Swan Lake Update 13). It includes improvements to dependency resolution.</em>

## Update Ballerina

Run the command below to update your current Ballerina installation directly to 2201.13.2 by using the [Ballerina Update Tool](https://ballerina.io/learn/update-tool/).

```
$ bal dist pull 2201.13.2
```

## Install Ballerina

If you have not installed Ballerina, then, download the [installers](/downloads/) to install.
